# galca.app · sitio estático

Subir el contenido de esta carpeta a la raíz del dominio galca.app.

- index.html — página completa (CSS y JS incluidos, sin librerías).
- favicon-32.png, icon-180.png — copiar desde ../ (favicon-mono-32.png → favicon-32.png, icon-mono-180.png → icon-180.png).
- tablero.mp4 — exportar la animación de media/Tablero Video y guardarla aquí. Si no existe, el cuadro muestra un aviso discreto.

Contacto: hoy dice contacto@galca.app (provisional). Buscar y reemplazar en index.html.
Fuentes: Google Fonts (Red Hat Display, Public Sans); para servir sin red, descargarlas y usar @font-face.
